## About

I'm a developer focused on **privacy-first, local-first software**. My main project is **Diviso**, an open-source AI agent that runs entirely on your own hardware — from a phone running Termux to a GPU workstation — and works with local models (Ollama) or any major provider by API key.

I care about:
- Software that works offline and on modest hardware
- Agents with real safety rails: approval gates, sandboxes, cost caps
- Clean, tested, dependency-light code

## 🚀 Featured Project — Diviso

[![Diviso — local-first AI agent](https://raw.githubusercontent.com/Neuzant/diviso-agent/main/docs/images/social-preview.png)](https://github.com/Neuzant/diviso-agent)

**[Diviso](https://github.com/Neuzant/diviso-agent)** — a local-first AI agent with a ReAct loop and planner, persistent memory + RAG over your local files, a multi-agent team (Researcher / Coder / Reviewer), an MCP client, approval-gated tools in a workspace sandbox, and a guarded scheduler. Python stdlib-only core, with installers for Linux, macOS, Windows, Termux and Docker.
